# AI Proxy Usage Guide

## Recommended use

Use `clash/strict-ai-exit.yaml` for:

- ChatGPT
- Claude
- Cursor
- Gemini
- HuggingFace
- GitHub AI workflows

The goal is stable identity through the DMIT Xray Reality exit.

## Browser profile

Create a dedicated browser profile for AI services.

Avoid mixing:

- long-term China IP browsing history
- temporary US proxy sessions
- multiple accounts in one browser profile

## Validation

Expected exit:

```
IPv4: DMIT VPS public IP
WebRTC: No Public IP Leak
IPv6: disabled
DNS: proxy controlled
```
